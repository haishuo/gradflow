## Release decision

The current repository may be tagged and cited as an **internal research
release candidate**. Before a public archival release intended for third-party
reuse:

1. choose and add an explicit license for copyright-controlled GradFlow work;
2. obtain and record permissions for each historical source set, or generate
   and test a source-excluded public artifact;
3. retain the excluded-file list and original hashes so the scientific lineage
   remains auditable; and
4. ensure any eventual paper archive follows the publisher and data-repository
   terms actually selected.

This explicit blocker satisfies A4's requirement to resolve **or flag** the
question. It does not close the legal question.
